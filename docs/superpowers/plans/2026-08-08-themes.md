# Themes System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a visual theme system with 4 themes (Pip-Boy, Old Paper, Cave Writings, Noir Detective) that the DM can switch live across all connected clients.

**Architecture:** CSS custom properties on `<body>` for theme values, a `config` table for persistence, Socket.IO for real-time sync, and tileable PNG textures for paper/stone/grain effects.

**Tech Stack:** Node.js, Express, SQLite (better-sqlite3), Socket.IO, vanilla HTML/CSS/JS, Google Fonts, CSS custom properties

## Global Constraints

- UI language: Portuguese (Brazilian)
- Database: SQLite via better-sqlite3, WAL mode
- Real-time: Socket.IO for theme sync
- No frontend framework — vanilla DOM manipulation
- All three CSS files (dashboard, quests, terminal) must use the same variable names
- Texture images must be small tileable PNGs

### Task 2: Server — Theme config routes + Socket.IO

**Files:**
- Create: `server/routes/config.js`
- Modify: `server/server.js:26-30` (routes) and `:42` (socket)

**Interfaces:**
- Consumes: `configQueries` from Task 1
- Produces: `GET /api/config/theme`, `PUT /api/config/theme`, `theme:changed` socket event

- [ ] **Step 1: Create config routes**

Create `server/routes/config.js`:

```javascript
const express = require("express");
const router = express.Router();
const { configQueries } = require("../db");

const VALID_THEMES = ["pipboy", "oldpaper", "cave", "noir"];

// GET /api/config/theme - get current theme
router.get("/theme", (req, res) => {
  const row = configQueries.get.get("theme");
  res.json({ theme: row ? row.value : "pipboy" });
});

// PUT /api/config/theme - set theme and broadcast
router.put("/theme", (req, res) => {
  const { theme } = req.body;
  if (!theme || !VALID_THEMES.includes(theme)) {
    return res.status(400).json({ error: "Invalid theme" });
  }

  configQueries.set.run("theme", theme);

  const io = req.app.locals.io;
  io.emit("theme:changed", { theme });

  res.json({ theme });
});

module.exports = router;
```

- [ ] **Step 2: Register route in server.js**

In `server/server.js`, add after the existing route registrations (after line 30):

```javascript
app.use("/api/config", require("./routes/config"));
```

- [ ] **Step 3: Send theme on player connection**

In `server/sockets.js`, find where players join their room and add theme emission. Read the file first to find the right location.

```javascript
// After the player joins their room:
```

### Task 7: JavaScript — Theme switcher for DM dashboard

**Files:**
- Modify: `public/dm/dashboard.js`

**Interfaces:**
- Consumes: `GET /api/config/theme`, `PUT /api/config/theme`, `theme:changed` socket event
- Produces: Theme switching + real-time sync

- [ ] **Step 1: Add theme loading on init**

At the top of `dashboard.js` (after global variables), add:

```javascript
let currentTheme = "pipboy";
```

In the `init()` function (at the bottom of the file), add:

```javascript
// Load current theme
fetch("/api/config/theme")
  .then(r => r.json())
  .then(data => {
    currentTheme = data.theme;
    document.body.className = "theme-" + currentTheme;
    document.getElementById("theme-select").value = currentTheme;
  });
```

- [ ] **Step 2: Add theme change handler**

After the init call, add:

```javascript
// Theme switcher
document.getElementById("theme-select").addEventListener("change", (e) => {
  const theme = e.target.value;
  fetch("/api/config/theme", {
    method: "PUT",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ theme })
  });
});

// Listen for theme changes from server
socket.on("theme:changed", (data) => {
  currentTheme = data.theme;
  document.body.className = "theme-" + currentTheme;
  document.getElementById("theme-select").value = currentTheme;
});
```
